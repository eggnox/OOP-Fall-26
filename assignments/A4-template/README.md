
# Assignment 4 — Statistics

## Overview

This assignment solves the Kattis Statistics problem using object-oriented programming, inheritance, an abstract base class, and the Template Method design pattern.

## Kattis Problem

https://open.kattis.com/problems/statistics

## Design Patterns

- Template Method Pattern
- Inheritance using Python's built-in list class
- Abstract Base Class using the instructor-provided Kattis class
